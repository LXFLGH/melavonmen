FarmCodeNote

农场经营 × 塔防 · 内置视觉小说剧情

开发中 · alpha

围绕一座会自己生长的农场：作物、火车运输、机器人自动化、哥布林突袭，外加一条可切换的视觉小说剧情线。整个项目 C++17 零第三方依赖，前端用 WebView 渲染，前后端保持逐比特可复现的一致性。

  • 确定性：同一存档同一输入，模拟结果逐比特一致（worldgen bit-identical）。
  • 三端桥接：CLI / GUI / HTTP 三种前端共用同一套 ActionDispatcher 仲裁。
  • 自带测试：SELFTEST 单元测试 + GUI / CLI 全路径覆盖，发版前必须全绿。
