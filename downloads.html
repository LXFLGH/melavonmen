SKILL / CODEX PLUGIN

Melavonmen 3.1.0

在 Codex 中搜索源码、定位定义、沿调用图检查变更影响，再把核实过的实现事实同步到 Wiki。插件使用自有的 Python 索引和 MCP 服务，并保留 Doc/Wiki、素材和漂移校验器。

代码检索

  • 结构索引可在本地运行，支持关键词、定义定位、调用图和分支刷新。
  • 混合检索在配置嵌入模型后支持按含义找源码和搜索相似实现。
  • Wiki 校验可发现漏收录源码、失效符号路由、过期页哈希和 Unicode 路径重命名。
