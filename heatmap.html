这张图与 GitHub 主页热力图有什么不同？
  • GitHub 主页热力图只统计公开仓库的提交，除非在 Settings → Public profile 勾选 “Include private contributions”。私有仓库的提交在主页上完全不计入。
  • 本页把私有仓库的 git 记录也纳入：远端 API 拉取全分支；FarmCodeNote 另含本机克隆里尚未推送的提交。
  • 额外给出 GitHub 不提供的维度：代码行数（numstat 汇总）、周×小时时段分布、分支 / 本机快照分布、tag 发布日。
  • 行数分级采用非零日分位数（P25 / P50 / P75 / P90），首次整仓同步这类超大提交会自然饱和在最高档，不会压平其余格子。

口径：日期取提交的 author date（+08:00）；同一提交在多个分支出现时仅计 1 次；仅本地 表示尚未推送到 GitHub；整仓 表示该提交单次新增 ≥ 5 万行（多为首次整仓同步）。切换上方项目按钮可查看单个仓库或全部合并视图，合并视图的每条提交带项目标签。
