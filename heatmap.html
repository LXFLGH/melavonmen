为什么这张图比 GitHub 个人主页的热力图更全？
  • GitHub 主页热力图只统计公开仓库的提交，除非在 Settings → Public profile 勾选 “Include private contributions”。私有仓库的提交在主页上完全不计入（可用 GraphQL 的 restrictedContributionsCount 验证：为 0 就说明该开关是关的）。
  • 本页直接把 git 记录本身当数据源：远端 API 拉取全分支 ＋ 本机各克隆 git log --all，按 (日期, 标题) 归并历史重写产生的孪生提交，不依赖 GitHub 的可见性策略。
  • 额外给出 GitHub 不提供的维度：代码行数（--numstat 汇总）、周×小时时段分布、分支/本地快照分布、tag 发布日。
  • 行数分级采用非零日分位数，首次整仓同步这类超大提交会自然饱和在最高档，不会压平其余格子。

口径：日期取提交的 author date（+08:00）；同一提交在多个本地快照/分支出现时仅计 1 次；仅本地 表示尚未推送到 GitHub；整仓 表示该提交单次改动 ≥ 5 万行（多为首次整仓同步）。
